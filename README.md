# Livro-Fundamentos-de-Programacao-com-JavaScript
Este repositório tem como objetivo praticar os conceitos do livro Lógica de Programação e Algoritmos com JavaScript, de Edécio Fernando Iepsen (Novatec). A proposta é testar, na prática, o quanto o aprendizado por livros pode ser mais profundo do que cursos tradicionais.
