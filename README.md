# 📘 Respostas – Lógica de Programação e Algoritmos com JavaScript (2ª edição)

Este repositório explica onde encontrar as **respostas oficiais disponibilizadas pela Editora Novatec** para os exercícios do livro.

⚠️ Importante: a editora **não fornece um gabarito completo** de todos os exercícios.  
O material disponível é chamado de **Arquivos de Apoio / Código-fonte do livro**.

---

## 📥 Onde baixar as respostas oficiais

As respostas podem ser baixadas diretamente no site da editora:

👉 https://novatec.com.br/livros/logica-programacao-algoritmos-com-javascript/

Na página do livro, procure pela seção:

**Downloads / Arquivos de apoio / Código-fonte**

Baixe o arquivo `.zip` disponibilizado pela editora.
